# KeyForge
KeyForge это нативное приложение для настройки клавиатур через VIA-протокол с поддержкой JSON-конфигураций. Работает без браузера и консоли, достаточно скачать установщик из Releases. Поддерживает автоматическое определение клавиатуры, загрузку пользовательских раскладок через импорт JSON, сохранение профилей и кроссплатформенность:
